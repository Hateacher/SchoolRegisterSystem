# frontend（前端）

校园活动报名系统前端，基于 Vue 3 + Vite 模板搭建。后端接口约定与启动方式见项目根目录 [README.md](../README.md)。

## 推荐开发环境

[VS Code](https://code.visualstudio.com/) + [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar) 插件（如安装过 Vetur 请禁用）。

## 推荐浏览器环境

- 基于 Chromium 的浏览器（Chrome、Edge、Brave 等）：
  - [Vue.js devtools](https://chromewebstore.google.com/detail/vuejs-devtools/nhdogjmejiglipccpnnnanhbledajbpd)
  - [在 Chrome DevTools 中开启自定义对象格式化](http://bit.ly/object-formatters)
- Firefox：
  - [Vue.js devtools](https://addons.mozilla.org/en-US/firefox/addon/vue-js-devtools/)
  - [在 Firefox DevTools 中开启自定义对象格式化](https://fxdx.dev/firefox-devtools-custom-object-formatters/)

## 自定义配置

参见 [Vite 配置参考](https://vite.dev/config/)。

## 项目命令

```sh
npm install
```

安装依赖。

### 开发模式启动（热更新）

```sh
npm run dev
```

### 生产环境构建（压缩打包）

```sh
npm run build
```

### 代码检查（ESLint）

```sh
npm run lint
```
